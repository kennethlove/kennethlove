# Howdy 💖

My name is Kenneth but I prefer **klove** (*kay love*). I'm a longtime Python and
Django engineer, programming speaker/teacher/mentor, and open source
contributor. I use they/them/any pronouns. I watch a lot of horror movies and
absolutely adore the Discworld series. Let's talk about something interesting!

## Recent projects

- [gobblin-games]: A browser-based battle royale simulator. Forked from [hangrier_games].
- [jjhub]: A forge for [Jujutsu].
- [thekennethlove.com]: My personal site.

## Python/Django libraries

- [django-admin-action-hero]: An abstract base class and a couple of
  implementations showing how to make Django admin actions more generic.
- [django-braces]: Mixins for Django's class-based views. Makes CBVs easier and
  nicer to work with.
- [django-brackets]: A spiritual successor to `django-braces`. More class-based
  view mixins.
- [django-drifter]: A tool for quickly reseting migrations during development.
- [django-middle-management]: A tool for currently running management commands
  remotely.

## Other fun projects

- [hangrier_games]: A browser-based *Hunger Games* simulator, v2.
- [rust-bf]: A Brainfuck interpreter, generator, REPL, and IDE.
- [skidmarks]: A streak tracker for daily/weekly streaks.
